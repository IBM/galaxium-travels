Draft · Reviewed

Summary

The original plan proposed a GET /bookings/{id}/export.ics endpoint, a matching MCP tool and an "Add to Calendar" button. All three are implemented on this branch, and the implementation goes beyond the plan: RFC 5545 escaping and line folding, DTSTAMP/CALSCALE, extra error codes and more tests. This document records what was built, where it deviated, and the remaining hardening work.

Open items

  • test_get_booking_ics_cancelled_booking only asserts BEGIN:VCALENDAR.
  • No test confirms the ICS route is listed as an MCP tool or how a text/calendar response is surfaced.
  • AGENTS.md footguns on MCP ordering, SessionLocal() in MCP tools and "add matching MCP tool" are out of date.
