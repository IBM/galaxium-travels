# Scenario 1: Ask Mode - Code Analysis

## 🎯 Objective
Use Bob's Ask Mode to analyze a legacy inventory system and create architecture documentation.

## ⏱️ Time: 25 minutes

## 📁 Files Provided
- `app.py` - Legacy Flask application
- `db_config.py` - Database configuration
- `requirements.txt` - Python dependencies

## 🚀 What You'll Do

1. Analyze the codebase with Bob
2. Generate architecture diagram
3. Identify security vulnerabilities
4. Document findings

## 📝 Prompts to Use

### Step 1: Understand the System
```
Analyze app.py and db_config.py. Explain what this application does, 
its main components, and how data flows through the system. 
Generate a Mermaid architecture diagram.
```

### Step 2: Security Audit
```
Perform a security audit. Identify all vulnerabilities, 
categorize by severity, and explain the impact.
```

### Step 3: Deep Dive
```
Show me exactly how an attacker could exploit the SQL injection 
vulnerability. Provide example malicious payloads.
```

## ✅ Deliverables

Save your work in the `deliverables/` folder:
- Architecture diagram
- Security report

## 🎯 Success Criteria

- ✅ System architecture documented
- ✅ At least 3 vulnerabilities identified
- ✅ Attack scenarios explained
- ✅ Deliverables saved

Good luck! 🚀
